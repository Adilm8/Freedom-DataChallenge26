## Общие правила для всех брифов

- База: ветка `claude/project-thread-8xbevo` (после мержа — `main`). Новая ветка на задачу, имя — в брифе.
- Коммиты: автор `Adilm8 <adtsco00@gmail.com>` (`git config user.name Adilm8`, `git config user.email adtsco00@gmail.com`). Формат Conventional Commits. Никаких упоминаний ассистентов и трейлеров `Co-Authored-By` в коммитах и PR.
- Трогать только файлы, перечисленные в брифе. Не добавлять зависимости.
- Не отправлять во внешние сервисы реальные звонки `p4-ru-*` и файлы `data/raw/`, `.env`, PDF гайда (там секретная ссылка). Работать только с синтетическими чатами `p1-*`.
- Результат: push ветки и короткое сообщение Лиде, что сделано и как проверить.
