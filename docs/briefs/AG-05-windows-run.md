# AG-05. Проверить запуск на Windows и дописать README

**Когда:** после вехи M3 (~20:00 UTC), когда есть рабочий UI.

**Цель:** жюри и Лида запускают проект на Windows с нуля по README без вопросов.

**Сделать:**
1. На ноутбуке Лиды в PowerShell с чистого клона выполнить шаги из `README.md` и записать каждую ошибку или неочевидный шаг.
2. Дописать в `README.md` раздел «Windows (PowerShell)»: установка `uv`, venv, зависимости, `.env`, загрузка данных (API и файл), запуск, открыть UI, запуск тестов.
3. Проверить кириллицу и казахские буквы в UI и в экспорте CSV (Excel).

**Не трогать:** код. Если что-то не работает — описать ошибку в сообщении Лиде, не чинить.
**Ветка:** `docs/readme-windows`. Коммит: `docs: Windows run instructions`.
