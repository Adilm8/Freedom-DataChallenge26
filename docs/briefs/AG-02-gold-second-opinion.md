# AG-02. Независимая вторая разметка gold (только синтетические чаты)

**Цель:** вторая независимая разметка тех же диалогов, что размечает Claude. Сравнение двух разметок покажет спорные места, и Лида проверит только расхождения, а не всё подряд.

**Важно:** не смотри черновик Claude (`data/gold/drafts/`), иначе разметка перестанет быть независимой. Только чаты `p1-*`, без звонков `p4-*`.

**Контекст:** `docs/checklist.md` целиком (критерии, шкалы, памятка, порядок расчёта) — это единственный источник правил. `data/gold/README.md` — формат. Диалоги — `DEV_readable.md` (список id даст Лида).

**Сделать:** для каждого диалога из списка файл `data/gold/second_opinion/<conversation_id>.json`:
```json
{
  "conversation_id": "p1-ru-001",
  "labeled_by": "second-opinion",
  "criteria": {
    "01": {"answer": "yes", "reason": "1–2 предложения по-русски", "evidence": ["m9"]},
    "04": {"answer": 20, "reason": "...", "evidence": ["m9", "m11"]}
  }
}
```
- `answer`: `yes` / `no` / `na` для 01, 02, 03, 05, 07, 08; ступень `0/5/10/15/20` или `na` для 04; `0/4/7/10` для 06. N/A только там, где чек-лист его разрешает.
- `evidence`: номера реплик `m<idx>`, где `idx` — порядковый номер реплики в транскрипте с нуля.
- Оценивается только оператор; бот и системные сообщения — контекст.
- Итог не считать (это делает код).

**Не трогать:** всё, кроме `data/gold/second_opinion/`.
**Готово, когда:** файл на каждый диалог из списка, все 8 критериев, JSON валиден.
**Ветка:** `eval/gold-second-opinion`. Коммит: `eval(data): independent second-opinion labels for <N> chats`.
