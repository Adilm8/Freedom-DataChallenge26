# План реализации

> Статус: черновик v0.3 · Обновлено: 2026-11-07 · Владелец: Claude · Пересматриваем после каждого этапа
> Это пошаговый план. Длительности примерные и нужны только для того, чтобы видеть, если шаг затянулся. Жёстких точек две: выдача контрольных транскриптов и сдача с проверкой 2026-11-08 10:00–12:00 по местному времени ([Q-01](spec/open-questions.md)).
> Если шаг идёт примерно в полтора раза дольше оценки, смотрим раздел 3 «Что режем» и решаем, что убрать.

## 0. Как распределено время

Организаторы уточнили (`docs/task/organizer-message-2026-11-07.md`): точного совпадения с эталоном до каждого балла не ждут, смотрят на близость и обоснованность, а при отборе учитывают удобство интерфейса, полноту процесса, интересные дополнительные возможности и технический подход. Угадывать их внутреннюю методику не просят. Лида просит уделить интерфейсу и доп. функциям значительное время. Отсюда:

- **Примерно половина всей работы — интерфейс и дополнительные возможности** (шаги 5, 6, 11–14, 17–24, 26–27).
- Качество интерфейса закладываем с первого шага фронта: палитра, шрифты, бейджи и состояния делаются сразу хорошими, а в конце остаётся шлифовка, а не переделка.
- Цикл подгонки точности короткий: 2 итерации плюс проверка на holdout вместо «пока растёт». Важнее обоснованность (FR-EVAL-16), учёт устной речи (FR-EVAL-17) и воспроизводимость (FR-EVAL-20).
- Ядро и основной сценарий — до M3, доп. функции — на этапе 4 по приоритету, на M4 заморозка.

## 3. Что режем, если отстаём (в этом порядке)

1. Публичный деплой (FR-OPS-06).
2. Локальная модель (FR-EVAL-13).
3. Функции C из раздела 5.10: темы обращений (FR-ANL-02), статистика апелляций (FR-ANL-03), печать (FR-UX-05), тёмная тема (FR-UX-06), горячие клавиши (FR-UX-08).
4. Мультиязычные обоснования (FR-EVAL-15), отличия версий чек-листа (FR-CHK-08).
5. Голосование и подвопросы для шкал (FR-EVAL-11).
6. Правила-страховки с `override` (оставляем только `flag`).
7. Сравнение оценок в карточке (FR-CARD-06) → только на экране качества.
8. Экран качества в UI → таблицы только в презентации и README (FR-OPS-05).
9. Оценка стоимости до запуска (FR-UX-03) → только фактическая после.
10. Режим «только расхождения» в экране gold (FR-GOLD-03).
11. Прокси записи → прямая ссылка «открыть запись».
12. Таймлайн диалога (FR-UX-01) → факты списком в карточке.
13. Дашборд группы (FR-ANL-01) → сводка над списком.

Не режем никогда: расчёт баллов, доказательства с переходом к реплике, N/A с причиной, флаг 08, пометка «требует проверки» при нехватке данных (FR-EVAL-16), учёт устной речи в звонках (FR-EVAL-17), воспроизводимость (FR-EVAL-20), апелляция с пересчётом, редактор чек-листа с применением, контрольный прогон, README с описанием и метриками, качество интерфейса основного сценария и проход по удобству (FR-UX-07).
