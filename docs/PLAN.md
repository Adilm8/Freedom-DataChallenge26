## 1. Шаги

Шаги внутри этапа с разными исполнителями идут параллельно. Задачи на одни и те же файлы — последовательно. Контрольные точки M0–M6 — это проверка «всё ли работает» в конце этапа, а не время на часах.

**M0 · Архитектура (готово):** ТЗ, архитектура, `CONTRACTS.md` v0.1, ADR-001…013, ответы Лиды. Ждём «старт» от Лиды.

## 3. Что режем, если отстаём (в этом порядке)

1. Публичный деплой (FR-OPS-06).
2. Локальная модель (FR-EVAL-13).
3. Мультиязычные обоснования (FR-EVAL-15), отличия версий чек-листа (FR-CHK-08).
4. Голосование и подвопросы для шкал (FR-EVAL-11).
5. Правила-страховки с `override` (оставляем только `flag`).
6. Сравнение оценок в карточке (FR-CARD-06) → только на экране качества.
7. Экран качества в UI → таблицы только в презентации и README (FR-OPS-05).
8. Режим «только расхождения» в экране gold (FR-GOLD-03).
9. Прокси записи → прямая ссылка «открыть запись».

Не режем никогда: расчёт баллов, доказательства с переходом к реплике, N/A с причиной, флаг 08, апелляция с пересчётом, редактор чек-листа с применением, контрольный прогон, README с описанием и метриками, качество интерфейса основного сценария.

## 4. Риски

| # | Риск | Вероятность / вред | Что делаем |
|---|---|---|---|
| R1 | Мало или плохая gold-разметка → не знаем точность | средн. / высокий | черновик делает Claude в сессии, экран проверки, два захода |
| R2 | Модель ломает JSON или выдумывает цитаты | средн. / средний | строгая схема, валидатор, ретрай, `needs_review` |
| R3 | Кончился бюджет OpenRouter | средн. / высокий | расход в каждом прогоне, лимит на ключе, дорогая модель только на gold и финале |
| R4 | Лимиты Gemini free | высок. / низкий | семафор 2, backoff, Gemini только для отладки конвейера |
| R5 | Переобучение на DEV | средн. / высокий | holdout, никаких цитат DEV в промпте, правки — общими правилами |
| R6 | Контроль отличается от DEV (новые сценарии, звонки, другие системные фразы) | средн. / высокий | нормализация без жёстких шаблонов, факты — подсказки, словари в конфиге, модель видит сырые system-сообщения |
| R7 | Замена критерия ломает что-то на сцене | низк. / высокий | ADR-003, репетиции на шагах 16 и 25 |
| R8 | Запись звонка не играет (CORS, истёкшая подпись) | средн. / средний | прокси через бэкенд, запасная ссылка |
| R9 | API организаторов недоступен на контроле | низк. / высокий | импорт из файла (FR-DATA-02), скачать сразу при выдаче |
| R10 | Не успеваем вдвоём | средн. / высокий | контрольные точки, заморозка фич на M4, порядок отсечения |
| R11 | Windows-специфика (пути, кодировки) | средн. / средний | `pathlib`, UTF-8 везде, проверка на ноутбуке Лиды после этапов 1 и 3 |
