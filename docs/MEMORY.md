Долговременная память проекта для Claude. Подключена в `CLAUDE.md`, читается в каждой сессии.
Здесь живёт то, что иначе пришлось бы спрашивать у Лиды заново. Держи файл коротким: один факт — одна строка, устаревшее удаляй.
Статус работы — в `docs/PROGRESS.md`, решения с причинами — в `docs/DECISIONS.md`.

## Команда и режим

## LLM и бюджет
- Внешние модели: OpenRouter (платный, небольшой баланс на весь хакатон) + бесплатный ключ Gemini. Ключи Лида кладёт в `.env` сама, в чат не присылает.
- **OpenRouter: ни одного платного вызова без согласия Лиды.** Модели на каждом ключе выбираем вместе с ней.
- **API моделей — только для конвейера, реалистичных прогонов и сравнения моделей для презентации.** Gold-разметку, анализ, фикстуры и тестовые данные Claude делает в сессии без API.
- Gemini free — отладка конвейера на синтетических чатах; реальные звонки `p4-ru-*` туда не отправлять. OpenRouter — eval и финальные прогоны.
- Локальная модель (Ollama) — опционально, позже.
- У Лиды есть Antigravity Pro (Gemini 3.8 Flash): самодостаточные задачи без ядра оценки уходят туда через брифы `docs/briefs/AG-*.md`. Туда тоже только синтетические чаты, без звонков `p4-*`.

## Среда
- Облачные сессии — среда `Freedom-DataChallenge26`: открыты `openrouter.ai` и хост API организаторов; ключи OpenRouter и Gemini подставляет прокси (network secrets, Bearer), в коде ключ может быть пустым. `generativelanguage.googleapis.com` нет в Allowed domains — при блокировке добавить.
- URL API организаторов содержит подпись `sig` = секрет. Он есть внутри PDF-гайда, поэтому гайд в git не класть.
- Снапшот DEV: `data/raw/DEV.json`; читаемая версия — `data/raw/DEV_readable.md` (и копия в папке проекта `Freedom Datathon/research/`).
- Ноутбук Лиды — Windows (имя устройства «macbook»). Команды для него — PowerShell. Локальная папка проекта — `Freedom Datathon\` (папка `Freedom-DataChallenge26\` там пока не git-клон).
