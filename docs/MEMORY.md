# MEMORY

Долговременная память проекта для Claude. Подключена в `CLAUDE.md`, читается в каждой сессии.
Здесь живёт то, что иначе пришлось бы спрашивать у Лиды заново. Держи файл коротким: один факт — одна строка, устаревшее удаляй.
Статус работы — в `docs/PROGRESS.md`, решения с причинами — в `docs/DECISIONS.md`.

## Команда и режим
- Работаем вдвоём: Лида + Claude, без других участников. Общение — по-русски, коротко.
- Код решения пишем только после совместного исследования (`docs/research/` → `docs/architecture/`).

## LLM и бюджет
- Внешние модели: OpenRouter (платный, небольшой баланс на весь хакатон) + бесплатный ключ Gemini. Ключи Лида кладёт в `.env` сама, в чат не присылает.
- Gemini free — черновая работа и массовые прогоны; реальные звонки `p4-ru-*` туда не отправлять. OpenRouter — eval и финальные прогоны.
- Локальная модель (Ollama) — опционально, позже.

## Среда
- Облачные сессии — среда `Freedom-DataChallenge26` (открыты `openrouter.ai` и хост API организаторов). Default-среда эти хосты блокирует. Для Gemini нужно добавить `generativelanguage.googleapis.com`.
- URL API организаторов содержит подпись `sig` = секрет. Он есть внутри PDF-гайда, поэтому гайд в git не класть.
- Снапшот DEV: `data/raw/DEV.json`; читаемая версия — `data/raw/DEV_readable.md` (и копия в папке проекта `Freedom Datathon/research/`).
- Локальная папка проекта на Macbook Лиды — `Freedom Datathon/` (там же клон репо `Freedom-DataChallenge26/`).

## Наблюдения о данных (подробно — `docs/research/01-data-overview.md`)
- Во всех 60 чатах сначала бот AIM, затем эскалация на оператора; оценивается только оператор.
- Системные сообщения несут сигналы для критериев: «Личность клиента подтверждена», «Оператор закрыл чат», «Соединение прервано», «Клиент покинул чат».
