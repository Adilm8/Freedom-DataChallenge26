# Сценарий защиты (5 минут) и репетиция замены критерия

> Время по пунктам — из гайда организаторов. Диалоги ниже — запасные из DEV; если в контроле найдётся подходящий, показываем его.

## 1. Сценарий

| Минута | Что показываем | Где | Требования |
|---|---|---|---|
| 0:00–1:00 | Дашборд контрольного набора: средний итог, слабые критерии, грубые ошибки → клик → список с фильтром → открываем диалог | дашборд → список → карточка | FR-ANL-01, FR-CARD-01, 02 |
| 1:00–3:00 | Таймлайн диалога и обзор (тема, решён ли вопрос). Оценка по критериям: ответ, баллы, вес, обоснование, рекомендация оператору; клик по доказательству → подсветка реплики; «Нет» с проверенным участком; пример N/A с причиной; флаг грубой ошибки; итог и секции; модель и цена оценки; у звонка — клик → плеер на нужной секунде | карточка | FR-RES-*, FR-CARD-03, 04 |
| 3:00–4:00 | Режим «Аналитик»: оспорить критерий с комментарием → режим «Проверяющий»: очередь, фрагмент, изменить ответ с причиной → карточка: AI → решение → новый итог | карточка, апелляции | FR-APL-* |
| 4:00–5:00 | Чек-лист: поменять вес → итоги пересчитаны мгновенно, без LLM; заменить критерий → применить к выданным диалогам (по одному вызову на диалог) → новый результат в карточке | чек-лист → прогресс → карточка | FR-CHK-02, 03, 06, 07, 10 |

Если остаётся 10–15 секунд: экран качества (точность против нашей gold-разметки по критериям и языкам).

**Регламент:** по гайду защита — максимум 5 минут, точное расписание организаторы сообщат. Основной сценарий держим в 5 минутах. Если дадут больше (до 10), добавляем запасной блок:

| Доп. минуты | Что |
|---|---|
| +1.5 | Архитектура одним слайдом: факты кодом → LLM → проверка цитат → баллы кодом; почему так (Contact Lens, Cresta, исследования) |
| +1.5 | Экран качества: согласие с gold по критериям и языкам, сравнение моделей и стратегий по точности, цене и времени |
| +1 | Сравнение двух моделей или двух версий чек-листа на одном диалоге (FR-CARD-06) |
| +1 | Честность процесса: сырой ответ модели, проверка цитат, стоимость одной оценки |
| +1 | Живой новый диалог: жюри или мы набираем короткий чат прямо в UI → оценка за ~30 с (FR-DATA-07) |
| +0.5 | Очередь «требует проверки»: где модели не хватило данных, она так и сказала (FR-EVAL-16, FR-UX-02) |

**Материалы:** слайды (FR-PRES-01) и описание проекта в README (FR-PRES-02); цифры в них собирает `eval/report.py` из сохранённых прогонов (FR-PRES-03).

## 3. Репетиция замены критерия (шаги 16 и 32 плана)

Цель — убедиться, что новый критерий работает без правки кода (FR-CHK-07, ADR-003).

1. Открыть «Чек-лист», активная версия `default`.
2. **Вариант А — правка:** у 07 «Завершение» поменять формулировку и вес 5 → 10. Сохранить как новую версию.
3. **Вариант Б — замена:** удалить 05, добавить новый критерий, например «Предупреждение об ожидании», тип `binary`, N/A разрешён («ожидания не было»), вес 15, «Да, когда…», «Нет, когда…». Сохранить.
4. **Вариант В — новая шкала:** новый критерий типа `scale` со ступенями 0 / 5 / 10. Сохранить.
5. Применить каждую версию к 3–5 диалогам. Проверить: новый критерий в карточке, ответы осмысленны, доказательства кликаются, итог пересчитан с новыми весами, старая оценка осталась со старой версией.
6. Засечь время от открытия редактора до результата. Цель — меньше 2 минут на сцене.
