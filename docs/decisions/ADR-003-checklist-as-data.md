# ADR-003: Чек-лист — версионируемые данные; код не ветвится по коду критерия

- Статус: **Принято** (следует из требований)
- Дата: 2026-11-07 · Кто решил: команда по требованиям задания
- Связано: FR-CHK-01…07, NFR-09

## Контекст
На контроле организаторы попросят заменить критерий через UI и применить чек-лист к диалогам. Любой `if key == "07"` в коде сломает это на сцене.

## Решение
Чек-лист — JSON (`CONTRACTS.md` §1) в `checklist_version.body`. Промпт, схема ответа, валидатор и баллы строятся из него. Инструкции «Да, когда…», условия N/A, шкалы, группы, справки и правила-страховки — поля критерия. Версии неизменяемы; правка = новая версия.

## Последствия
Чек-лист по умолчанию можно улучшать (точнее формулировать инструкции) без правки кода — это тоже проходит через eval. Нужна репетиция замены критерия (`spec/demo-scenario.md`).

## Как пересмотреть
Не пересматриваем.
