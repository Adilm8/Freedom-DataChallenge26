# ADR-005: Фронт — чистые ES-модули без сборки, компоненты монтируются в div

- Статус: **Принято** (требование: HTML/CSS/JS, адаптация под Dynamics 365)
- Дата: 2026-11-07 · Кто решил: требования задания
- Связано: NFR-08, `architecture/frontend.md`

## Решение
Без фреймворков и сборки. Компонент = `mount(el, params)`, параметры из query-строки, `fetch` только в `js/api.js` с настраиваемым базовым URL, CSS с префиксом `cqa-`. Тонкие `pages/*.html` — заготовки под HTML web resource. Режим `?mock=1` читает фикстуры по контракту, чтобы фронт не ждал бэкенд.

## Последствия
Меньше удобства, чем у React, но ноль инфраструктуры и прямая переносимость. Компоненты должны быть маленькими.
