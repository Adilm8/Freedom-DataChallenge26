# ADR-013: Демо локально; публичный деплой — опция при запасе времени

- Статус: **Принято** (локально), деплой — **Отложено**
- Дата: 2026-11-07 · Кто решил: Лида
- Связано: FR-OPS-06, A-4, Q-08

## Контекст
Защита идёт с демонстрацией экрана. Публичный URL мог бы дать жюри потрогать систему самим и добавить баллов, но это отдельная работа и риск.

## Решение
Разрабатываем и показываем локально с ноутбука Лиды. Архитектура деплой не блокирует: один процесс FastAPI, SQLite-файл, настройки через переменные окружения, фронт — статика того же сервера.

## Если решим деплоить (после M4, при запасе и с согласия Лиды)
- Оценка: 2–3 часа вместе с защитой.
- Обязательно: демо-режим только для чтения; запуск прогонов и правка чек-листа — по паролю из переменной окружения. Иначе любой посетитель потратит кредиты OpenRouter.
- Ключи и URL организаторов — в секретах хостинга, не в репозитории.
- SQLite на хостинге может стираться при перезапуске: БД с результатами контроля загружаем при старте из экспорта или держим на постоянном диске.
- Записи звонков — только через прокси бэкенда, ссылки с подписью не светим.
