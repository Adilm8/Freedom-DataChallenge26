# ADR-007: Язык обоснований — русский для всех диалогов

- Статус: **Принято**
- Дата: 2026-11-07 · Кто решил: Лида
- Связано: FR-EVAL-09

## Контекст
Диалоги на RU, KZ, EN. Жюри и проверяющий читают по-русски. Модели лучше классифицируют, чем генерируют, на казахском. Amazon Contact Lens использует «язык формы» независимо от языка диалога.

## Решение
`settings.output_language = "ru"`: обоснования и причины N/A на русском, цитаты — в языке оригинала. Настройка в чек-листе, можно сменить без кода.

## Варианты
| Вариант | Плюсы | Минусы |
|---|---|---|
| **RU всегда** | одинаково читается, проще сравнивать | — |
| Язык диалога | естественно для KZ/EN | жюри хуже читает KZ, модель хуже пишет на KZ |

## Отмечено на будущее
Лида: «возможно стоит сделать на всех основных языках». Это FR-EVAL-15 (C): `output_language` уже настройка чек-листа, остаётся выбор при запуске и проверка качества KZ-обоснований на eval.
