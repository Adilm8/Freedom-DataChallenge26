# ADR-004: SQLite + SQLModel, изменчивые поля в JSON, без миграций

- Статус: **Принято**
- Дата: 2026-11-07 · Кто решил: команда
- Связано: NFR-07, NFR-09, `architecture/data-model.md`

## Контекст
Один процесс, один пользователь, 75 диалогов. Схема результата будет меняться по ходу.

## Решение
SQLite-файл `data/cqa.db`, SQLModel. Стабильные поля — колонки (для фильтров и сортировки), изменчивые (факты, доказательства, `ScoreResult`, тело чек-листа, сырые ответы) — JSON. Миграций нет: `scripts/reset_db.py` пересоздаёт схему и сидит чек-лист по умолчанию; данные реимпортируются из снапшота, оценки перегоняются.

## Последствия
Новое поле результата — без миграции. Сброс БД стирает оценки и апелляции: перед демо и контролем схему не меняем.

## Как пересмотреть
Если понадобится деплой с несколькими пользователями — Postgres через тот же SQLModel.
