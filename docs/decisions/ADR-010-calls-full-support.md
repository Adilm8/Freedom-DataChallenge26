# ADR-010: Звонки — полноценно: тот же конвейер, плеер, переход по времени

- Статус: **Принято**
- Дата: 2026-11-07 · Кто решил: Лида
- Связано: FR-CARD-04, FR-DATA-05, FR-EVAL-10

## Решение
Звонки идут через тот же конвейер. Дополнительно: сегменты удержания и консультации с коллегой (реплики оператора там помечены `internal` и не считаются общением с клиентом), смещение записи с учётом пауз «Запись приостановлена / возобновлена», ручная поправка смещения в карточке, прокси записи через бэкенд, если браузер не открывает `audio_url`. Звонки не отправляются в Gemini free.

## Риски
Подписанная ссылка на запись может истечь; начало записи может не совпадать с первой репликой. Проверяем на всех 5 звонках вручную в фазе UI.
