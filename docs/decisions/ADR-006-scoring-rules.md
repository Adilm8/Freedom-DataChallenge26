# ADR-006: Правила расчёта и их уточнения

- Статус: **Принято**
- Дата: 2026-11-07 · Кто решил: Claude по тексту чек-листа
- Связано: FR-SCORE-01…08

## Решение
- «Да» = вес, «Нет» = 0, шкала = `вес × ступень / max ступени`, флаг — без баллов и вне весов.
- N/A исключает критерий; итог = `Σ баллов / Σ применимых весов × 100`. Так итог корректен и при сумме весов ≠ 100 (новый чек-лист с защиты).
- Округление итога до `settings.rounding` знаков **половина вверх** (`Decimal`), потому что `round()` в Python округляет к чётному.
- Нет применимых критериев с весом → `total = null`.
- Грубая ошибка: `critical_policy = "flag"` (как в PDF: «отмечаются отдельно»), итог не обнуляется. Вариант `zero_total` есть в настройках на случай, если эталон жюри поведёт себя иначе.
- Секции: баллы, применимый вес, процент от применимого веса секции.
- Контрольный тест: пример из чек-листа → 94.38.

## Как пересмотреть
Если узнаем, как эталон считает флаг или секции, — меняем настройку в чек-листе, а не код.
