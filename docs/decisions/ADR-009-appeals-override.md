# ADR-009: Апелляция — надстройка над AI-оценкой, а не перезапись

- Статус: **Принято** (следует из требований и практики Contact Lens / Quality AI)
- Дата: 2026-11-07
- Связано: FR-APL-01…07

## Решение
AI-ответы неизменны. Апелляция хранит комментарий и снимок оспоренного ответа. Решение проверяющего (подтвердить / изменить + обязательная причина) пишет `final_*` у критерия и пересчитывает `final_score` тем же `scoring`. Карточка показывает три слоя: AI → решение → финал. Одна открытая апелляция на критерий.

## Последствия
Апелляции — ещё и данные для калибровки: расхождения AI с проверяющим можно разбирать как расхождения с gold.
