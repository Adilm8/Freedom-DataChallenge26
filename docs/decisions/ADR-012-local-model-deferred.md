# ADR-012: Локальная модель — отложено

- Статус: **Отложено**
- Дата: 2026-11-07 · Кто решил: Лида
- Связано: FR-EVAL-13

## Обновление 2026-11-07 11:40
Лида может выделить бюджет на аренду GPU. Это открывает вариант «открытая модель на арендованном GPU» (тот же OpenAI-совместимый провайдер) для критерия «разнообразие подходов». Дообучение по-прежнему не рекомендую: 65 диалогов DEV — слишком мало, высокий риск переобучения, и на это уйдёт время, нужное для точности основного конвейера. Решаем после M4 по запасу времени.

## Решение
Фокус на облачных моделях. Провайдер `ollama` поддерживается тем же OpenAI-совместимым кодом, поэтому, если в фазе полировки останется время, это 30–60 минут: поставить Ollama на ноутбук, прогнать eval и показать результат на экране качества как «разнообразие подходов».
