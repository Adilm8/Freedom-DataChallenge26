# ADR-008: Прогоны — фоновые задачи в процессе, без очередей

- Статус: **Принято**
- Дата: 2026-11-07 · Кто решил: команда
- Связано: FR-EVAL-01, NFR-02, NFR-04

## Решение
`POST /api/runs` создаёт `evaluation_run` и запускает asyncio-задачу в процессе FastAPI. Параллельность — семафор на провайдера. Прогресс — в БД, фронт опрашивает `GET /api/runs/{id}`. Сбой одного диалога пишется в `failed` и не останавливает прогон. После перезапуска сервера незавершённый прогон помечается `partial`, его можно перезапустить для оставшихся.

## Варианты
Celery/RQ, Step Functions — лишняя инфраструктура для 75 диалогов.
