# ADR-011: Справка о продуктах Freedom Broker для критерия 04

- Статус: **Принято** как подсказка; оставляем по результату eval
- Дата: 2026-11-07 · Кто решил: Лида (искать в открытых источниках), Claude (как подключить)
- Связано: FR-EVAL-14, `data/knowledge/freedom_broker_kb.md`

## Контекст
Для 04 нужно отличать верную рекомендацию от ошибочной. Внутренней базы нет; часть фактов есть в открытых источниках, часть — в том, как одинаково отвечают операторы DEV.

## Решение
Справка — markdown в `data/knowledge/`, подключается к критерию полем `context_refs` (по умолчанию у 04) и подставляется в блок критерия с правилом «подсказка, а не эталон: штраф только при явном противоречии».

## Риски
Раздел 2 справки собран из DEV-диалогов, поэтому на DEV (включая holdout) он завысит согласие по 04. Проверяем вклад справки сравнением «с / без» и не считаем рост на DEV доказательством для контроля. Если контроль про другие темы, справка просто не сработает, но и не навредит.
