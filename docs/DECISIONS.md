- 2026-11-07 — URL API организаторов хранится только в `.env` (`ORGANIZER_API_URL`): в нём подпись `sig`, по сути ключ.
- 2026-11-07 — Python 3.11 (`.python-version`), окружение через `uv venv`.
- 2026-11-07 — `temperature` передаём только моделям, которые его принимают (у новых моделей Anthropic sampling-параметры дают 400). Валидный JSON — через `response_format`/валидацию, цитаты проверяет код.
- 2026-11-07 — LLM: внешние модели через OpenRouter (основной) и бесплатный Gemini (черновые прогоны), оба через OpenAI-совместимый API и SDK `openai`. Claude API напрямую пока не используем. Причина: выбор Лиды, ограниченный бюджет.
- 2026-11-07 — Реальные звонки `p4-ru-*` не отправляем в бесплатный Gemini. Причина: бесплатный тариф может использовать данные для обучения.
