# Gold-разметка DEV

Эталон для `eval/run_eval.py`. Черновик делает Claude в рабочей сессии (без API), Лида проверяет; файл `gold_labels.json` правит только человек.

Формат (`gold_labels.json`):

```json
{
  "checklist_version": "default-v1",
  "items": {
    "p1-ru-001": {
      "labeled_by": "Lida",
      "criteria": {
        "01": {"answer": "yes"},
        "02": {"answer": "na"},
        "03": {"answer": "na"},
        "04": {"answer": 20},
        "05": {"answer": "yes"},
        "06": {"answer": 10},
        "07": {"answer": "yes"},
        "08": {"answer": "no"}
      },
      "total": 100.0,
      "notes": "необязательно",
      "uncertain": ["03"],
      "reviewed_at": "2026-11-07T20:15:00+00:00",
      "changed": ["01", "04"]
    }
  }
}
```

`answer`: `yes` / `no` / `na` для бинарных, номер ступени (`0/5/10/15/20`, `0/4/7/10`) или `na` для шкал. `total` считает `scoring.py`, в разметке — для контроля.

Поля, которые пишет экран «Проверка gold» (`#/gold`, `backend/app/api/gold.py`):

- `uncertain` — критерии, помеченные проверяющим как «не уверены» (клавиша `U`); при разборе ошибок такие критерии смотрим отдельно.
- `changed` — критерии, где ответ проверяющего отличается от черновика Claude.
- `reviewed_at` — время, когда диалог отмечен «всё ок» (`Enter`); `null`, пока идёт только автосохранение.

Каталог `data/gold/` целиком: `selection.json` (выборка), `split.json` (dev/holdout), `drafts/<id>.json` (черновики), `second_opinion/<id>.json` (вторая независимая разметка, необязательна), `gold_labels.json` (итог).

## Вторая независимая разметка (`second_opinion/`)

22 чата из gold (без звонков `p4-*`) размечены независимо от черновиков Claude: Gemini 3.8 Flash в Antigravity по `docs/checklist.md`, бриф `docs/briefs/AG-02`. Это не эталон: файл на диалог с ответом, обоснованием и репликами по 8 критериям. Нужна, чтобы видеть, где сам чек-лист читается по-разному.

- 07 — 9 из 22: «попрощался» вторая разметка считает выполнением, gold читает строго (без итога и предложения помощи — «Нет», решение Лиды).
- 06 — 9 из 22: шкала в обе стороны, без явного перекоса.
- 04 — 6 из 22: предложение платных «частных» услуг вторая разметка снижает в 04 и 06.
- 08 — 3 из 22 (p1-en-014, p1-kz-015, p1-ru-009): gold видит грубую ошибку, вторая разметка нет; в p1-ru-009 — данные до идентификации, которые по решению Лиды дают и 03 «Нет», и 08 «Да».
