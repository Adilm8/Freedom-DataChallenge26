# Eval

- `run_eval.py` — прогон оценщика по gold-разметке (`data/gold/gold_labels.json`, разбиение `split.json`: dev / holdout) и метрики близости: точное совпадение и ± 1 ступень по критериям, MAE итога и доля в пределах ± 5 / ± 10, флаг 08 (recall / precision), разрезы по языкам и каналам, калибровка уверенности, стабильность (`--repeat 2`), цена и время. Платный прогон — только с `--approved "кто и когда разрешил"`.
- `metrics.py` — сами метрики (тесты — `tests/test_metrics.py`).
- `report.py` — таблицы для README и слайдов из сохранённых прогонов (FR-PRES-03): цифры берутся только из `eval/runs/`.
- Результаты — `eval/runs/<время>_<провайдер>_<модель>_<стратегия>_<split>.json` (не в git); экран «Качество» (`#/quality`) читает ту же папку.

Любое изменение промпта — прогон до и после на dev, проверка на holdout.
